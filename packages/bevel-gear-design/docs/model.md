# 计算模型与适用范围

本文说明独立实现的数学定义。几何与标准评级、无载 TCA、整轮 FE 和局部半解析属于不同模型，不能互换同名输出。

## 几何与无载接触

零偏置相交轴齿轮由整数齿数、大轮外端节径、齿宽、轴交角、螺旋角、压力角和变位等显式输入建立。直齿采用球面渐开线工作面；弧齿采用双面刀盘展成包络，刀尖根过渡和工程连接分别定义。CAD 内核长度为 mm，公开长度及网格顶点换算为 m。

TCA 在实际有限工作面求对应点位置一致和法向相切，并检查裁切边界。首接触和无载从动角由真实齿面对确定，不强制等于名义齿数比；几何接触成功不说明弹性接触区已得到解析。

## 整轮 FE 接触

`prepare_generated_ltca` 建立双轮闭实体、体网格和线弹性系统；同轮各齿共享同一刚度矩阵。`generated_refinement_tracks` 在真实工作面定义局部体网格控制。`solve_native_fe_contact` 采用两侧实际 FE 边界交片；`solve_generated_distributed_fe_ltca` 保留 CAD 曲面 Gauss 积分路线。两者均使用 P0 非负压力面元，节点—面入口另作兼容。

接触柔度按需凝聚为 `C[:,J]=Σ Wᵀ K_ff⁻¹ W[:,J]`。分布牵引的 `f_i=p_i A_i` 为投影面元合力，W按实际FE形函数积分；设参考平面法向为n，两工作面外法向为N，牵引系数分别为 `−N₁/(N₁·n)` 与 `+N₂/(N₂·n)`，与投影间隙导数功共轭。积分阶数独立控制，逐Gauss点与小片平均约束分别检查。没有叠加半空间柔度。C 的单位为m/N，求解约束为：

```text
r = g + C f − ell θ ≥ 0
f ≥ 0
f_i r_i = 0
ellᵀ f = T
```

g、r 用 m，f 用 N，ell 为实际轴力臂、用 m，θ 用 rad，T 用 N·m。返回接触互补、扭矩残差和能量核验。当前采用小变形线弹性、P1 四面体和固定孔壁，不含摩擦、塑性、温升或整机动力学。

总受载 TE 定义为实际从动角与理想齿数比运动的差：`TE_total=φ_loaded+(z₁/z₂)α`。原生 FE 交片路线保存这个总量及当次线性化转角增量；末次增量属于数值迭代，不能解释为独立的弹性 TE。仅在无载相切和网格参考修正均已独立确定的路线中，才分别报告相应分量。

从动轴切线刚度采用当前几何和接触分支的线性化定义 `Kθ=ell_Aᵀ C_A⁻¹ ell_A`，单位 N·m/rad，其中 A 为承载自由度集合。该导数冻结当次载荷算子及接触分支；它不是包含有限转角几何刚度的完整非线性路径导数，也不能用 T/θ 或线位移刚度代替。

分布牵引压力在原参考面元内为常量。守恒中心P1显示保留所有原中心标量，内部承载时每个中心面积权重仍为A，满足 `∫p_h dA=Σf_i`；缺邻域时拒绝延伸。显示不重新定义原Gauss力矩、TE或原峰值。节点兼容路线另采用 `p_i=f_i/a_i`、`a_i=Σ A_triangle/3`，不能混用二者面积。

受载几何外迭代重建 W、间隙和力臂，并复用同一材料边界条件下的 K 分解。原生路线在当前刚体姿态重建真实 FE 三角形交片；仿射 FE 高度、形函数和刚体速度按交片精确积分，核查原交片顶点及实际有限转角下的位移迹。CAD 积分路线另重新投影 NURBS 和同一 FE 材料点。仅刚体重投影不能代替材料位移更新。体网格的表面尺寸、接触深层细化厚度与主体尺寸分别控制；压力面元和积分阶数也分别检验。弱 KKT 接受、局部余隙、空间收敛和物理试验验证属于不同状态。

## 局部半解析接触

矩形面元弹性影响系数采用解析积分，以非周期 FFT 加速有限域卷积并保留有限自影响项。合成模量及法向位移核为：

```text
1/E* = Σ(1−ν²)/E
u(x) = ∫ p(x′)/[π E* |x−x′|] dA′
```

压力仍需数值求解非负约束及有符号力矩平衡。常压力单元积分面积为参考切平面 dx·dy；实际曲面点、四角、面积雅可比和有效域另存。逐格求交检查真实有限齿面，加载后重新投影核验线性化与力臂，未知几何不补作零间隙。

该模型不含有限齿厚、齿根／轮体、轴承和跨齿结构柔度，闭合及 dT/dθ 仅属于局部半空间。整轮 FE 已含局部压陷，未经近／远场一致分解不能直接叠加两种柔度。

## 压力、面积和周期最大值

分布牵引FE与半解析均区分参考平面压力面积和实际曲面面积；节点兼容FE以真实三维三角形面积定义集总压力。实际单齿工作面为真实面积占比的分母；完整齿面子午投影不是等面积展开，不能按彩色像素求接触面积。

将各已解相位 i、周期等价齿对 k 的原 P1 场映回同一参考材料工作面，定义 `p_env(w_f,h)=max_i,k p_i,k(w_f,h)`，并保存 argmax、原状态峰值和未知标志。若任一所需状态未知，该处包络仍未知，已有压力值只提供下界。包络不能积分成某一瞬时合力或扭矩，也不等于涂层印迹。

原精确三角等值域接口按 `{max p_i≥L}=union{p_i≥L}` 构造压力等值域。公开四联图按半解析瞬时／周期、FE瞬时／周期排列，各用自己的线性绝对MPa色标，均从0蓝色开始。默认工程显示对FE原场作逐齿法向合力守恒恢复，并在同齿相邻已解相位间随接触中心插值；原解不覆盖，另提供`--view raw`。恢复压力和插值最大值是工程显示估计，不是新增平衡解，不作峰压精度验证；算法及限制见[压力显示说明](contact_pressure_display.md)。不作RGB平滑或拟合椭圆。

相位采样、接触求解网格和显示查询网格分别记录。完整一齿距须有全部接受的相位及重复端点，窗外邻齿另行核验；完整采样不证明连续相位极值或严格压力网格收敛。真实工作面已确认零压为蓝色，未知为灰色网纹，齿面外白色。

## 标准强度

ISO 10300 兼容评级分别提供 B1/B2 齿根路线；AGMA 2003C10 具有独立 I/J、载荷、温度、尺寸、硬度和寿命定义。不得混合路线中的系数或择取最低应力。材料和三点 S-N 曲线由调用者给定，不是牌号数据库或工程推荐。

独立 2014 B1 名义应力链采用：

```text
H0 = Z_MB · Z_LS · Z_E · Z_K · sqrt(Fn / (l_middle · rho_rel))
F0 = Ft / (bv · mn) · Y_Fa · Y_Sa · Y_epsilon · Y_BS · Y_LS
```

随后按各自 KA、Kv、齿向和横向分配系数修正。危险截面采用有界方程求根，保留残差及迭代；动载方法 B 保留四个速度区间。`Z_K=0.85` 和默认有效齿宽比例 0.85 是不同量。

该名义链支持非负中点法向总侧隙 j_n，两轮弧齿厚各减 `j_n/(2 cos(alpha_n))`，有效齿厚变位分别为 `(+x_sm,−x_sm)−j_n/(4 m_n cos(alpha_n))`。两工作侧的几何、刀尖与危险截面保持各自定义。未实现的制造／多根分支明确报错。

2014 名义函数本身不返回容量、安全系数或寿命；统一工作流可另用显式设计应力限值评估。兼容评级的容量、许用应力、安全系数和 S-N 损伤则保留各自方法语义，不能自动与独立名义链拼接。

已有解析、守恒、方程和保存参照的数值检查不构成标准认证、全部参数域保证或真实齿面压力的实验验证。当前案例、数值边界和后续计划统一见项目 README。
