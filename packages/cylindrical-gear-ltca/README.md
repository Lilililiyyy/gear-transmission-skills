# 保留的圆柱齿轮重建计算内核

本目录保存现有 `cylindrical-gear-ltca` 公开工程的选定文件快照：完整 `gear_contact` Python模块、原安装元数据、依赖约束、MIT许可和模型／接口说明。所选原文件保持原字节，未重写公式或修改分支。

快照身份见 `../../src/gear_transmission/kernel_snapshot.json`：记录来源项目、来源仓库基准提交及每个文件SHA256。来源工作树包含尚未提交更新，因此该提交只是来源背景，逐文件哈希才是本次快照的实际身份。

运行时验证实际加载的全部内核Python文件与快照一致；同名的其他安装包不会被无声当作本内核。源码对应表见 `../../docs/source-map.json`。本次新增代码属于工作流适配，原计算内核属于现有新写重建实现；不把它标成厂商原始源码。

统一安装请使用项目根的 `pyproject.toml`，它同时安装 `gear_transmission` 和原导入名 `gear_contact`。这个快照与原项目中的同名发行包应放在独立环境使用，避免一个环境内两个发行包共同占用 `gear_contact`。

算法仍在原工程维护，本目录为明确固定版本的集成快照。后续同步必须重新记录工作树身份、文件哈希并通过数值对标；不要同时编辑两处公式。当前未复制原工程大型结果、厂商宿主、私有来源资料或Git目录。
