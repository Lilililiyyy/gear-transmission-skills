# 0.3.0 响应回归、收敛与设计比较

本次新增内容属于重建计算内核的设计接口与验证工具。数值回归检查版本变化；离散检查研究给定工况的空间和相位敏感性；MASTA 对标与物理验证另行记录，三者不能互相替代。

## 固定版本响应回归

```bash
python -B examples/response_regression.py --output output/response_regression --require-match
```

`examples/response_baseline.json` 由原提交 `1fa166a1b8ae3c3d37f53418b4ecbc5edf9635a2` 的实际求解建立，保存来源文件哈希、数值环境、输入、离散和比较判据。覆盖九个原有对标工况及一个普通 `coupled` 组合修形工况。检查时重新调用当前内核，基线响应只参加比较，不能作为求解输出。

报告 `response_regression.json` 区分完整基线检查和选定案例检查，保留逐字段差异、单位及绝对／相对容差。比较汇总 TE、刚度、中心和可用端点峰压，同时检查相位数组、索引与活动掩码。近零响应使用绝对容差；索引和活动掩码要求精确一致。每案另存本次实际输入及原数组。

普通检查不会刷新基线。算法有意变化时，应明确变更依据、与旧基线的差异和新的验证范围，再单独审查新基线。回归通过不表示与原组件数学问题等价，亦不表示达到实物预测精度。原 `run_benchmarks.py` 的 MASTA 等价性与精度状态保持独立。

## 空间与相位收敛矩阵

```bash
python -B examples/check_convergence_matrix.py --output output/convergence_matrix --require-convergence
python -B examples/check_convergence_matrix.py --output output/convergence_smoke --quick
```

矩阵覆盖外直齿组合修形、内斜齿、低载、强失准边缘承载和 18/77 ISO/Love 工况。正式默认条带数为 11／21／41，相位数为 16／32／64；研究一个方向时固定另一个方向。可显式指定案例、层级、固定离散及相对容差，输入与判据随报告保存。

每一级都实际求解，保存输入、原数组及平衡／互补残差；报告分别列出 TE、刚度、中心压力和可用端点压力的层级变化。有限层级结果仅说明所列指标在给定采样下的敏感性，不能证明整个参数域收敛。

`convergence_matrix.json` 中 `formal_convergence_passed` 只有正式计算且满足全部判据时才为真。快速模式仅检查执行流程，该字段为 `null`；与 `--require-convergence` 一起使用会失败。求解失败及未收敛工况保留诊断，不通过调整图形或补零掩盖。

正常 CI 执行固定基线回归和快速矩阵；在 GitHub Actions 手动运行时启用 `convergence` 输入，才执行完整矩阵。完整检查不通过时任务失败，并上传所有已保存结果供分析。

### 2026-11-12 实际验收

固定响应回归覆盖 10 案、138 项字段比较，全部通过。默认正式矩阵的 25 组唯一配置均通过原数组校核；组合修形外直齿及内斜齿通过全部离散判据，低载、强失准和 18/77 ISO/Love 工况未通过，故整体正式收敛状态为失败。

对三个未通过案例进一步采用条带 21／41／81（固定 64 相位）、相位 32／64／128（固定 41 条带），新增矩阵的 15 组唯一配置均通过原数组校核。相邻级仍采用原绝对容差加 2% 相对容差，没有放宽门槛：

| 工况 | 追加加密后的观察 | 正式状态 |
| --- | --- | --- |
| 低载 | 空间 41→81 的平均刚度变化 3.127%、受载长度变化 4.475%；相位两对相邻级通过 | 未通过 |
| 强失准 | 空间 41→81 的中心峰压变化 1.951%、受载长度变化 0.761%，最大线载变化仍为 2.684%；相位两对相邻级通过 | 未通过 |
| 18/77 ISO/Love | 空间 41→81 的 TE 峰峰值变化 6.938%；相位 64→128 的 TE 变化降至 0.0983%，但前一对相位级未通过 | 未通过 |

两轮固定的另一离散轴不同，不能直接把跨轮变化当作单轴改善。上述判断采用各轮内部相邻级；两轮共有的六组配置原数组逐值一致。完整正式矩阵目前预期返回未收敛退出码 2；这是被保留的数值限制，后续需研究接触边界离散及低载活动集敏感性，不能以本轮接口与验证工具更新宣称求解器已全面收敛。

## 修形比较的压力指标

`compare_designs`、`robust_design_search` 和 `sweep_parameter` 支持 `pressure_metric='center'|'endpoint'`，默认 `center`。指标同时控制逐工况压力、最坏工况压力、显式压力约束及 Pareto 筛选。

- `center`：原接触单元中心压力，保留既有默认数值。
- `endpoint`：所有相位真实独立端点压力的最大值。需要支持端点输出的延伸接触配置；缺失、空或非有限端点数据明确报错，不用中心值替代。

`DesignStudy.to_dict()` 保存指标定义和单位；`rows.max_pressure_mpa` 与 `design_summary.worst_pressure_mpa` 始终表示所选指标。`pressure_limit_pa` 的单位为 Pa；原 `AnalysisResult.summary.max_pressure_pa` 继续表示中心压力。`plot_design_study` 和其 CSV 使用已选指标，不重新按中心压力计算筛选结果。

压力约束由调用者提供；局部 Hertz 峰压不能直接代替标准接触应力或材料寿命结论。
