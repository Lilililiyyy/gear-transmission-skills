# 输出解释与验证

`run.json`保存终止阶段、实际状态、源码和环境身份、逐文件SHA256。失败时保留错误，`status=failed`；不能只看有无图片判断成功。`inputs.json`是已展开制造引用的SI请求。`report.md`为流程摘要，具体指标读取 `calculation/workflow.json`：

| 结果 | 正确含义 |
|---|---|
| `geometry`、`forces` | 实际计算的名义尺寸、诊断及切向／径向／轴向力；检查几何诊断和旋向约定 |
| `standard_rating` | 2014名义应力链、系数及齿根截面；不等于已实现全部ISO／AGMA容量、寿命与静强度 |
| `strength_assessment` | 使用显式设计应力限及目标安全系数；不合格仍是有效计算结果 |
| `manufacturing_binding` | 名义几何与各实际制造面的尺寸、齿厚和逐侧角度绑定；不替代制造精度检验 |
| `cad` | 实际CAD及m制三角网格文件；工程根连接不等同于真实刀具展成齿根 |
| `tca` | 各相位／齿对相切状态、选定分支与无载TE；有些相位失败则不能称全周期成功 |
| `ltca` | 原节点FE各相位及载荷扫的场、分担、TE、切线刚度和残差；读取逐状态单位与接受条件 |
| `masta_benchmark` | 仅同输入身份下的外部名义几何与强度逐量对比，不是接触压力或物理验证 |

接触扭矩保留符号；转速幅值与相位扫描顺序不指定真实转向。TE以从动轮角度差rad解释，转角秒需显式换算；总TE与纯弹性TE分别检查原字段。切线刚度为N·m/rad，不用T/θ替代导数。

统一LTCA孔壁固定，不包含轴承／轴／箱体系统。局部半解析不能用作整轮TE替代。原节点FE、原生分布P0牵引及半空间压力的离散和接受条件不同，不能混用曲线与云图。瞬时压力与周期采样最大值不同；未解析域为未知，未采相位极值与空间峰值保持未收敛。工程恢复和显示相位插值不增加新的力学平衡解。

`replay`先校验原文件和同环境身份，再从原输入重新求解。`replay.json`逐组比较原生数学结果内完整列表，记录rtol与atol；STEP／BREP的序列化字节、图片及CAD三角网格文件不作为数值等同性依据。通过仅表示当前代码与环境下这些数学结果可复现，不证明离散精度、实验精度或设计寿命。比较失败保持 `passed=false` 和差异字段路径。

`figures/zh/`使用原内核绘图，保存图、SI源表和清单。没有外部参照时不画对标图，未完成阶段不画相应结果；绘图不能生成缺失接触解。本次已执行直齿／弧齿几何强度、直齿单相位CAD／TCA／节点FE-LTCA及各自复算；全周期、弧齿接触及高级接触路线的端到端验收保持未验证，见本库评测记录。
